# Terra Food 安全整改记录（2026-09-12）

## 范围与结论

本轮基于 `perf/startup-mobile` 的 `87de400` 整改，验证只在小主机的独立 MySQL、Redis、上传目录和回环端口中执行。现有部署及生产数据未变更。

这不是“项目已绝对安全”的声明。稳定身份、会话撤销、写接口 CSRF、MCP 鉴权、审核版本、打卡并发与依赖升级已经形成可运行修复；图片资源租约和隔离解码、外部记忆物理清理、持久化发现缓存版本等较大改造仍需后续完成。为避免未完成实现继续产生安全影响，本版本默认关闭自动图片派生、孤图清理和公共发现缓存。

## 发布与回滚约束

1. 先备份并运行身份归属预检，无法证明的旧菜品保持未归属。
2. 后端与迁移先发布；旧会话统一失效并要求重新登录。
3. 再发布携带 CSRF、审核版本、sessionRevision 的前端。
4. 图片自动派生、孤图清理和发现缓存保持关闭，直到对应后续改造完成。
5. 身份与会话安全迁移是最低可运行版本，不允许回滚到按用户名授权或接受旧 Session principal 的代码。
6. 回滚不删除新增表、subjectId、原图或用户记录；外部记忆删除队列必须保留。
